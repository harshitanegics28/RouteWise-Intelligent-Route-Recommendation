# RouteWise – Intelligent Route Recommendation System

RouteWise is a web-based route recommendation prototype that combines shortest-distance routing with machine learning-based travel-time prediction.

## Features
- Interactive Manhattan map using Leaflet
- Source and destination selection
- Shortest-distance route calculation
- Road distance estimation
- ML-based travel-time prediction
- Python backend integrated with HTML, CSS, and JavaScript frontend

## Technologies Used
Python, HTML, CSS, JavaScript, Leaflet, OSMnx, Scikit-learn, and NYC Taxi Trip Duration Dataset (2016).

## Model Evaluation
- MAE: 174.14 seconds
- RMSE: 270.18 seconds
- R² Score: 0.6313

## Current Status
Functional local prototype. Advanced route recommendation features are planned for future development.
